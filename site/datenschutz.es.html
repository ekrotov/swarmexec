Privacidad_

Política de privacidad de este sitio web.

Esta declaración informa sobre el tratamiento de datos personales al visitar swarm-exec.cloud-surfers.net. Para otros servicios de Cloud Surfers GmbH se aplican los avisos enlazados en cada caso.

1. Responsable

Responsable en el sentido del RGPD es Cloud Surfers GmbH. La dirección y la representación figuran en el Aviso legal. Contacto en materia de protección de datos: eugen.krotov@cloud-surfers.de.

2. Hosting y archivos de registro del servidor

El sitio web se opera sobre infraestructura propia. Al acceder, el servidor web trata datos de acceso técnicamente necesarios que transmite su navegador:

  • la dirección IP del dispositivo que realiza la solicitud,
  • la fecha y la hora del acceso,
  • el recurso solicitado y el código de estado HTTP,
  • el volumen de datos transferido,
  • la página de referencia (referrer) así como la identificación del navegador y del sistema operativo (user-agent).

La finalidad es la entrega, la estabilidad y la seguridad del servicio. La base jurídica es el art. 6, apdo. 1, letra f del RGPD (interés legítimo en un funcionamiento seguro y operativo). Los datos de registro solo se conservan mientras sea necesario para estas finalidades.

3. Medición de audiencia con una herramienta operada por nosotros mismos

Para mejorar el servicio empleamos una herramienta de análisis propia y operada internamente (Umami), que se ejecuta en nuestra propia infraestructura bajo stats.cloud-surfers.net. El análisis se realiza deliberadamente minimizando los datos:

  • No se establecen cookies ni se elaboran perfiles de usuario entre dispositivos.
  • Los datos permanecen en nuestra propia infraestructura; no se produce ninguna cesión a terceros ni transferencia a terceros países.
  • Las direcciones IP no se almacenan de forma permanente.
  • Se recopilan datos de uso agregados como las páginas consultadas, la página de referencia, la región de origen aproximada así como el tipo de navegador y de dispositivo.

La finalidad es comprender el uso y seguir desarrollando el sitio web. La base jurídica es el art. 6, apdo. 1, letra f del RGPD (interés legítimo en un diseño acorde a las necesidades). Dado que en su dispositivo no se utilizan cookies ni técnicas comparables, no se requiere consentimiento para ello.

4. Grabación de sesiones (Session Replay)

Como complemento a la medición de audiencia, utilizamos una función de la misma herramienta operada por nosotros mismos (Umami, stats.cloud-surfers.net) para la grabación de sesiones individuales, con el fin de poder seguir el transcurso de una visita y mejorar la usabilidad de las páginas. En particular se registran:

  • los movimientos del ratón y del puntero, los clics así como el comportamiento de desplazamiento,
  • los cambios de página y los contenidos consultados dentro del sitio web,
  • datos técnicos como el tamaño de la ventana y de la pantalla, el navegador y el tipo de dispositivo.

También este tratamiento se realiza exclusivamente en nuestra propia infraestructura; no se produce cesión a terceros ni transferencia a terceros países, y no se elaboran perfiles entre dispositivos. Este sitio web se compone únicamente de páginas informativas de acceso público y no contiene formularios para la introducción de datos personales.

La grabación de sesiones va más allá de una mera medición de audiencia. La base jurídica es nuestro interés legítimo en un diseño comprensible y fácil de usar del servicio (art. 6, apdo. 1, letra f del RGPD). Puede oponerse a este tratamiento en cualquier momento con efecto para el futuro (art. 21 del RGPD); para ello, diríjase a la dirección de contacto indicada en el punto 1.

5. Enlaces externos

El sitio web enlaza a servicios externos (entre otros, el repositorio de GitLab y Docker Hub). Al abrir uno de esos enlaces abandona esta página; no tenemos influencia alguna sobre el tratamiento que allí se realice. En el caso de Docker Hub (Docker, Inc., EE. UU.) esto puede suponer una transferencia a un tercer país. Se aplican los avisos de privacidad del proveedor correspondiente.

6. Sus derechos

En el marco de los requisitos legales tiene derecho de acceso (art. 15), rectificación (art. 16), supresión (art. 17), limitación del tratamiento (art. 18), portabilidad de los datos (art. 20) así como un derecho de oposición frente a los tratamientos basados en intereses legítimos (art. 21 del RGPD). Asimismo, existe un derecho a presentar una reclamación ante una autoridad de control de protección de datos. Para ejercerlos, diríjase a la dirección de contacto indicada más arriba.
