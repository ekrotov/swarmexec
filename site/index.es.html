swarmexec_

docker exec -it para todo el clúster de Docker Swarm.

Obtén una shell interactiva (o ejecuta un comando puntual) dentro de cualquier contenedor de un Swarm — además de logs y gestión de volúmenes en todo el swarm — desde una sola terminal, sin necesidad de conectarte por SSH al nodo que casualmente ejecuta la tarea. Un pequeño agente por nodo, una CLI/TUI programable, autenticación mTLS y un registro de auditoría.

$ swarmexec init # despliega el agente en cada nodo $ swarmexec exec web -- sh # abre una shell en una tarea, en cualquier nodo $ swarmexec ui # TUI interactiva
El agente (por nodo) está en Docker Hub: logleio/swarmexec-agent
