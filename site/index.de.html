swarmexec_

Clusterweites docker exec -it für Docker Swarm.

Öffne eine interaktive Shell (oder führe einen einmaligen Befehl aus) in jedem Container eines Swarms — dazu Logs und swarmweite Volume-Verwaltung — aus einem einzigen Terminal, ohne dich per SSH auf den Node zu verbinden, der die Task gerade ausführt. Ein kleiner Agent pro Node, eine skriptbare CLI/TUI, mTLS-Authentifizierung und ein Audit-Log.

$ swarmexec init # Agent auf jedem Node ausrollen $ swarmexec exec web -- sh # Shell in eine Task, beliebiger Node $ swarmexec ui # interaktive TUI
Der Agent (pro Node) liegt auf Docker Hub: logleio/swarmexec-agent
