Volumes & prune schedule_

Node-local volumes, seen and cleaned up cluster-wide.

On this page

  1. volume ls — list volumes
  2. volume rm — remove a volume
  3. prune-schedule — the agents' prune schedule

volume ls — list volumes

Lists volumes across all nodes and which nodes hold each. Swarm volumes are node-local, so the client queries every node and aggregates. Optional substring name filter. Columns: VOLUME  DRIVER  NODES  USED BY  AGE (plus SIZE with --size).

swarmexec volume ls [name-filter]
FlagDefaultDescription
--sizefalsealso compute each volume's on-disk size (slower: du per volume)
--sortnamesort by: name | nodes | used | age | size (size implies --size)
--reversefalsereverse the sort direction
--connect-timeout10sper-node connect timeout
--jsonfalseoutput JSON instead of a table

volume rm — remove a volume

Remove a volume on every node that holds it (--all) or on specific nodes (--node, repeatable). One of the two is required.

swarmexec volume rm <name> (--all | --node N …)
FlagDefaultDescription
--allfalseremove on every node that holds the volume
--node—remove only on these nodes (repeatable)
--forcefalsepass docker's force flag
-y, --yesfalsedo not prompt for confirmation
--connect-timeout10sper-node connect timeout

prune-schedule — the agents' prune schedule

Shows or sets the cluster-wide prune schedule. show prints it with the next five runs; set changes only the flags you give and enables the schedule. Saving updates the agent service, so the agents restart one by one; the command asks first.

swarmexec prune-schedule show swarmexec prune-schedule set --days mon-fri --start 03:00 --times 2 --tz Europe/Berlin
Flag (set)DefaultDescription
--daysevery daymon,tue,… or ranges like mon-fri
--start00:00first run of the day, HH:MM
--times1runs per day (1–24), the day split evenly from --start
--tzUTCIANA time zone of --days and --start
--categoriescontainers,images,buildcache,networksalso dangling-images and volumes
--containers-until24hkeep stopped containers this long after they stop; 0 keeps none
--label-filter—only prune objects with these labels; - clears
--disablefalseturn the schedule off and keep its settings
-y, --yesfalsedo not prompt before the agents restart
